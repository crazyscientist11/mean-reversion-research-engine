# Data

`example_synthetic_prices.csv` contains wholly synthetic, invented adjusted-close-like values. It is for loader demonstrations and tests only; it is not historical market data and must not be used for research conclusions.

Keep licensed exports and any Bloomberg-derived data under `data/private/` or `data/bloomberg/`; both are ignored by Git. Step 1 accepts wide CSV files with a `Date` column and one ticker per remaining column.
